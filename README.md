# Festival board

A shared set-times grid for a music festival. One HTML page, one Cloudflare Worker,
no build step, no accounts.

Live: https://iii-points.zstraub65.workers.dev

```
npm install
npm test
```

See `CLAUDE.md` for the rules that matter when changing this, and `HANDOFF.md` for
the current state and the plan to make it work for festivals other than III Points.
